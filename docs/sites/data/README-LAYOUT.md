# Data layout

As of 2026-09-22 (v2.3.0): monthly folders `YYYY-MM/` hold `week-WW.json` files.

Contract:

- Schema: `docs/sites/data/schema/week.schema.json`
- Catalog schema: `docs/sites/data/schema/catalog.schema.json`
- Golden example: `docs/sites/data/2026-09/week-38.json`

Per-day folders `YYYY-MM-DD/` were removed after the v2.2 migration.
